🦸‍♂️ Projeto: Classe Herói

Este projeto em JavaScript implementa uma classe chamada Heroi, que representa personagens com diferentes tipos (como mago, guerreiro, monge e ninja).
Cada herói pode realizar um ataque específico de acordo com seu tipo.

🚀 Tecnologias utilizadas

 1. JavaScript (ES6+)

 2. Node.js (opcional, para rodar no terminal)

    📌 Estrutura da Classe

A classe Heroi possui:

 1. Atributos:

 2. nome: Nome do herói

 3. idade: Idade do herói

 4. tipo: Tipo do herói (mago, guerreiro, monge, ninja)

Método:

 5. atacar(): Exibe no console uma mensagem personalizada de ataque baseada no tipo do herói.

 | Tipo      | Ataque                     |
| --------- | -------------------------- |
| Mago      | usou magia                 |
| Guerreiro | usou espada                |
| Monge     | usou artes marciais        |
| Ninja     | usou shuriken              |
| Outro     | fez um ataque desconhecido |

▶️ Como executar o projeto

Salve o código em um arquivo, por exemplo: heroi.js

No terminal, execute:
node heroi.js

📝 Observações

Este projeto foi criado como prática de Programação Orientada a Objetos (POO) em JavaScript, com foco em:

1. Classes e construtores

2. Estruturas condicionais (switch)

3. Loops (for...of)
